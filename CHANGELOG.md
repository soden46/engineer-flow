# Changelog

## v0.2.0 - 2026-08-24

### Added
- Project-evidence-aware external skill retrieval.
- Retrieval diagnostics.
- Explicit-name normalization regression coverage.
- Calibration and heldout benchmark infrastructure.

### Changed
- External skill retrieval can use bounded project evidence.
- Explicit skill names normalize `-`, `_`, `:`, and spaces consistently.

### Preserved
- Framework/language agnostic core.
- Maximum 2 specialists.
- Persistent memory infrastructure.
- Mandatory post-development security review.

### Known limitations
- morphology
- body-text blindness
- broad-heading over-capture
- support selection variance
