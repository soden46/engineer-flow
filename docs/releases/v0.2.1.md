# v0.2.1 - Browser-Driven UI Workflow Enrichment

## English

v0.2.1 is a patch release that enriches specialist engineering guidance for browser-driven UI and testing workflows. This release does not change routing behavior, resolver scoring, or routing metadata.

### What Changed

**Frontend UI**

- Browser-driven UI inspection guidance was added to `frontend-ui`.
- Reference-driven UI reconstruction guidance was added to `frontend-ui`.
- Guidance for DOM, accessibility-tree, and screenshot evidence was added.
- Responsive visual verification guidance was added.
- Implementation-boundary guidance preserves existing project conventions and third-party asset/content boundaries.

**Testing**

- Browser/E2E/Playwright regression guidance was added to `testing`.
- Visual responsive check guidance was added to `testing`.
- Mobile/desktop browser test guidance was added to `testing`.
- Durable browser test behavior principles were added.

### What Did Not Change

- Resolver logic is unchanged.
- Routing-visible metadata is unchanged.
- No `routing_terms` were introduced.
- The 0-2 specialist architecture is preserved.
- Mandatory post-development security review is preserved.

### Validation

```bash
npm run validate
npm run self-test
npm run test:normalization
npm run benchmark:routing
```

## Bahasa Indonesia

v0.2.1 adalah rilis patch yang memperkaya panduan engineering spesialis untuk alur kerja browser-driven UI dan testing. Rilis ini tidak mengubah perilaku routing, skoring resolver, atau metadata routing.

### Apa yang Berubah

**Frontend UI**

- Panduan inspeksi UI berbasis browser ditambahkan ke `frontend-ui`.
- Panduan rekonstruksi UI berbasis referensi ditambahkan ke `frontend-ui`.
- Panduan untuk evidence DOM, accessibility-tree, dan screenshot ditambahkan.
- Panduan verifikasi visual responsif ditambahkan.
- Panduan implementation-boundary menjaga konvensi project eksisting dan batas aset/konten pihak ketiga.

**Testing**

- Panduan regresi browser/E2E/Playwright ditambahkan ke `testing`.
- Panduan visual responsive check ditambahkan ke `testing`.
- Panduan browser test mobile/desktop ditambahkan ke `testing`.
- Prinsip durable browser test behavior ditambahkan.

### Apa yang Tidak Berubah

- Logika resolver tidak berubah.
- Metadata routing-visible tidak berubah.
- Tidak ada `routing_terms` yang diperkenalkan.
- Arsitektur 0-2 specialist tetap terjaga.
- Mandatory post-development security review tetap terjaga.

### Validasi

```bash
npm run validate
npm run self-test
npm run test:normalization
npm run benchmark:routing
```
