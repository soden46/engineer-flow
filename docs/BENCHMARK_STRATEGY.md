# Benchmark Strategy

Engineer Flow must not reuse consumed Laravel heldouts as final evidence.

## Development Tests

The v0.1 self-test covers:

- dynamic skill discovery;
- framework specialist preference;
- generic fallback;
- mode 0;
- primary-only routing;
- cross-cutting support;
- meta skill exclusion;
- malformed skill metadata;
- duplicate skill names;
- skill precedence;
- memory exclusion from specialist slots;
- hundreds of installed skills.

## Future Benchmark

Create a fresh multi-framework suite before claiming broad benchmark performance. Include tasks across Laravel, Flutter, Python, JavaScript/TypeScript, Go, Rust, APIs, DevOps, AI/LLM engineering, security, testing, documentation, and review.

Final benchmark cases must have independently authored expected routing assertions. Do not tune routing after inference starts.
