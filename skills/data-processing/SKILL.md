# Data Processing

Handle data with explicit contracts.

- Validate input shape and encoding.
- Stream or chunk large inputs.
- Preserve ordering, idempotency, and deduplication rules.
- Keep intermediate errors diagnosable.
- Avoid loading entire datasets when bounded processing works.
