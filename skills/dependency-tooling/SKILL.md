# Dependency Tooling

Keep tooling changes narrow and reproducible.

- Inspect existing package manager and lockfile conventions.
- Avoid unnecessary dependency additions.
- Prefer official upgrade paths and changelogs for version changes.
- Run build/lint/test commands affected by tooling changes.
- Preserve local environment assumptions.
