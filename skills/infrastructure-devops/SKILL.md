# Infrastructure DevOps

Change operations paths carefully.

- Inspect current environment and deployment conventions.
- Keep config portable and secret-safe.
- Prefer repeatable scripts over manual steps.
- Validate CI/build/deploy commands locally where feasible.
- Preserve observability, rollback, and failure visibility.
