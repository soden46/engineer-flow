# Debugging

Start from observed evidence.

- Capture exact error, command, input, and expected behavior.
- Reproduce before changing code when feasible.
- Separate symptoms from root cause.
- Make one focused fix and verify the failing path.
- Preserve useful diagnostics without leaking secrets.
